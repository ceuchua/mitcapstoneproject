A Machine Learning-Powered Graduate Tracer System for Employment Insights and Skill Trends

This project aims to design and develop a Tracer Study Information System with
Machine Learning-powered Analytics that should enable universities in  tracking graduate employment,
and for graduate students in identifying  in-demand industry skills through data analytics and machine learning.

The system is currently being developed using the following tools:
FastAPI and React with an integration of the Latent-Dirichlett Allocation model through FastAPI.

The system supports functionalities such as student portfolio management with skills analysis and administrative dashboards for university staff.
